## Features & Page Structure
1. **Client Demo Ribbon**: Easily dismissible preview header banner.
2. **Sticky Header**: Brand logo wordmark, full navigation, quick call CTA, and mobile hamburger drawer.
3. **Hero Section**: 24/7 care focus, dual CTAs (*Book Appointment* & *Emergency: Call Now*), and 3-point trust strip.
4. **24x7 Emergency Call Strip**: High-urgency red banner with both telephone numbers.
5. **About Section**: Ethical, patient-first care overview tailored to Bongaigaon with zero fabricated claims.
6. **Departments & Services Grid**: 10 clinical cards (General Medicine, Emergency, Surgery, O&G, Paediatrics, Orthopaedics, Diagnostics, Pharmacy, Radiology, ICU).
7. **Why Choose Us**: 6 honest core strengths.
8. **Doctor Profiles**: 4 sample doctor cards with appointment deep links.
9. **Patient Reviews**: Real 4.9-star Google rating with direct link to Google Business Profile.
10. **Appointment Form**: Direct WhatsApp integration pre-filling patient details to `+91 60015 51011`.
11. **Contact & Location**: Interactive embedded Google Map centered at coordinates `26.4687, 90.5617`.
12. **FAQ Accordion**: 8 answer-first questions with keyboard accessibility.
13. **Footer**: Social icons, emergency casualty status, copyright, and demo attribution.
14. **Mobile Sticky Action Bar**: Bottom bar with one-tap *Call*, *WhatsApp*, *Directions*, and *Book Visit*.

## Pushing Updates to GitHub
This directory is linked to the GitHub remote `origin`. Whenever you make updates inside this folder:

```bash
git push origin main
```
Any push to `main` will automatically trigger a new deployment on Vercel.
